# Bohr Product Competition Period 4 - Skill Packages

This repository is a public snapshot of the Skill packages built for the
Bohr Product Competition, Period 4. It contains one directory per challenge
under `skills/<challenge_id>/` inside the bundle.

## Layout

- `bohr-p4-skills-2026-11-24.zip` - bundle of all 57 Skill packages.
- `skills/<challenge_id>/SKILL.md` - Skill entry point and usage notes.
- `skills/<challenge_id>/scripts/` - implementation.
- `skills/<challenge_id>/references/` - optional reference material.
- `skills/<challenge_id>/GITHUB_URL.txt` - pointer to this repository.

## Usage

Download and unzip the bundle. Each challenge directory is a standalone
Skill package: read its `SKILL.md`, then run the documented entry point with
the official input and output directories. The packages do not contain
credentials, local test fixtures, or candidate answers.

## Notes

- The repository is provided for review and reproducibility.
- Content quality cannot be certified without the official cases and
  artifacts; such items are left as `UNKNOWN` rather than asserted.
